# ⭐ Meu Portfólio ⭐


Bem-vindo(a) ao repositório do meu portfólio pessoal! Este projeto foi desenvolvido para apresentar eu, meu trabalho, projetos e conteúdos de forma acessível e interativa na web.

## 📝 Sobre o Projeto

Este é um site estático construído para atuar como meu cartão de visitas digital. O portfólio conta com navegação entre diferentes páginas para melhor organizar os conteúdos, incluindo:

- **Página Inicial (`index.html`)**: Minha apresentação principal.
- **Canais (`canais.html`)**: Seção dedicada aos canais do youtube aos quais eu assisto e aprendo.
- **Playlists (`playlists.html`)**: Minhas playlists favoritas para escutar estudando.

## 🚀 Tecnologias Utilizadas

O projeto foi construído 100% do zero utilizando as tecnologias web fundamentais:

- ![HTML5](https://img.shields.io/badge/HTML5-E34F26?style=for-the-badge&logo=html5&logoColor=white) Para estruturação semântica de todo o conteúdo.
- ![CSS3](https://img.shields.io/badge/CSS3-1572B6?style=for-the-badge&logo=css3&logoColor=white) Para o layout, design e responsividade (pasta `/estilos`).
- ![JavaScript](https://img.shields.io/badge/JavaScript-F7DF1E?style=for-the-badge&logo=javascript&logoColor=black) Para adicionar interatividade ao site (`script.js`).
-  ![Canva](https://img.shields.io/badge/Canva-4B7CD4?style=for-the-badge&logo=Canva&logoColor=white) Para fazer o rascunho e a base do design
